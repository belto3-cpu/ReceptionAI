# ReceptionAI

## AI Receptionist for Small Businesses

This project is an AI phone receptionist designed for businesses such as:

- Hairdressers
- Barbers
- Beauty salons
- Dentists
- Physiotherapists
- Garages
- Veterinary clinics

### Features

- Answer incoming calls
- Book appointments
- Answer FAQs
- Send SMS confirmations
- Sync with business calendars
- Transfer urgent calls
